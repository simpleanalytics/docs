Websites on the Free plan need to show a Simple Analytics badge. Paid plans don't require a badge. If you'd rather not show it, [upgrade to a paid plan](https://www.simpleanalytics.com/pricing).

Build your badge and copy the code on [our badges page](https://www.simpleanalytics.com/badges). Place it in a footer that shows on every page of your website.

## What counts as a badge

Use the code from [our badges page](https://www.simpleanalytics.com/badges), or host an unchanged copy of the badge image yourself. Make sure the badge is visible and links to Simple Analytics.

If your website uses a [Content Security Policy](/csp), add `img-src simpleanalyticsbadges.com` to your policy.

## When the badge is missing

We regularly check if your website shows the badge. If we can't find it, we email you and show a notice in your dashboard. You then have 14 days to add the badge.

If the badge is still missing after those 14 days, we lock dashboard data, API access, and exports for that website. This also affects public dashboards and embedded charts. We keep collecting your page views and events while access is locked.

After you add the badge, click **Check badge again** in the dashboard notice. When we find the badge, access returns right away.
